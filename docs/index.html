04Why it exists

The decisions worth knowing about, written down.

EU engagements need EU portals

Every public collection is US-heavy. A Belgian red team showing a Verizon portal to a Ghent office worker is not fooling anyone.

Realism is the whole point

A portal that looks off gets closed in two seconds. These are built brand-by-brand with matching colors, type and layout.

Self-contained files

Every portal is one HTML file with inlined assets. No external requests, no broken images mid-engagement.
